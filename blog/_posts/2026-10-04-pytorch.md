### Work With Data

**Tensor:** "in mathematics, a tensor is an algebraic object that describes a multilinear relationship between sets of algebraic objects associated with a vector space." A vector is a type of tensor. The tutorial says that they are "very similar to arrays and matrices. In PyTorch, we use tensors to encode the inputs and outputs of a model, as well as the model's parameters."

**Initialize:**

    data = [[1, 2],[3, 4]]
    x_data = torch.tensor(data)

So create directly from data as above or from a NumPy array. 

Attributes include shape and datatype; by default created on the CPU. You can index and slice and joint tensors much list Python Lists. You can also matrix multiply. 

**Data Primitives**:

- DataLoader: "wraps an iterable around the Dataset to enable easy access"
- Dataset: "stores the samples and their corresponding labels"

Here's how to load the dataset:

     training_data = datasets.FashionMNIST(
         root="data",
         train=True,
         download=True,
         transform=v2.Compose([v2.ToImage(), v2.ToDtype(torch.float32, scale=True)])
     )

     test_data = datasets.FashionMNIST(
         root="data",
         train=False,
         download=True,
         transform=v2.Compose([v2.ToImage(), v2.ToDtype(torch.float32, scale=True)])
     )

The parameters are self-explanatory. "Root" is where the data is stored; "train" is whether the data is training or test; "download" is download from internet if not found in "root;" "transform" specifies the feature and label transformations. 

You can index the data like a list. You can create a custom dataset. 

Next, load the dataset into the `DataLoader` so youc an iterate. Iteration is good for model development and training. 

**Transforms**: this is the alst part of *Work with Data.* Transform is just a matter of manipulating / processing the data so that it's useful for training. "Transform" is one of the parameters of datasets. The other parameter not mentioned is "target_transform" that modifies the labels.
